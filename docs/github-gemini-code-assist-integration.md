# Github リポジトリと gemini-code-assist セットアップ

1. 以下にアクセスして `Install` を選択する
https://github.com/marketplace/gemini-code-assist

2. `Complete order and begin installation` を選択する
<img src="./images/github-gemini-code-assist-integration-01.png" width="50%">

3. `Only select repositories` で追加したいリポジトリを選択する
`Install` を選択する
<img src="./images/github-gemini-code-assist-integration-02.png" width="50%">

4. `Log in with Github` を選択する
<img src="./images/github-gemini-code-assist-integration-03.png" width="50%">

5. `Authorize Gemini Code Assist` を選択する
<img src="./images/github-gemini-code-assist-integration-04.png" width="50%">

6. ユーザーを選択し、`I accept the Terms of Service`, `I am over 18 years old` にチェックして `Continue` を選択する
<img src="./images/github-gemini-code-assist-integration-05.png" width="50%">


7. `Code review` と `Improve response Quality` にチェックして `Save` を選択する
`Comment severity` は `Medium` にしておく
<img src="./images/github-gemini-code-assist-integration-06.png" width="50%">

8. 以下のように Github に追加されていれば OK です
<img src="./images/github-gemini-code-assist-integration-07.png" width="50%">
<img src="./images/github-gemini-code-assist-integration-08.png" width="50%">
